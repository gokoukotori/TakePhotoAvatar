# Take Photo Avatar

Humanoidアバターの顔アップ・正面・右側面・背面と、三方向を横に並べた三面図をPNGで保存するUnity Editorツールです。

## 導入

Unity 2022.3のBuilt-in Render Pipelineを対象とします。

- この開発プロジェクトでは、`Packages/com.gokoukotori.take-photo-avatar`を埋め込みパッケージとして読み込みます。
- 別のプロジェクトでは、Unityの **Window → Package Manager → ＋ → Add package from disk…** から、このフォルダーの`package.json`を選択してください。
- `.tgz`を使用する場合は **Add package from tarball…** から選択してください。

VRChat SDK・NDMF・Modular Avatarへの依存はありません。撮影するアバター自身に必要なSDKやシェーダーは、別途そのプロジェクトへ導入してください。アバター素材は同梱していません。

## 使い方

1. **Tools → Gokoukotori → Take Photo Avatar → Aポーズ・顔アップ撮影ツール** を開きます。
2. 有効なHumanoid AnimatorがルートにあるPrefabまたはシーン上のアバターを指定します。
3. 腕の角度（水平から下へ30～90°、初期値45°）、全身の余白、顔の拡大率・中心位置、背景色を調整し、**プレビュー更新**を押します。90°では上腕が真下を向きます。透明な背景で保存する場合は **背景透過** をONにしてください。
4. 画像サイズ（512・1024・2048）と保存先を指定し、**PNGを5枚保存**を押します。

プレイモード中も撮影できます。プレイ中の衣装・表情を反映するには、PrefabではなくHierarchyの実行中アバターを指定してください。プレイ中も腕を指定角度に調整して、Aポーズ・顔アップを撮影します。モードの切り替え中は撮影できません。

プレイ中は撮影用の複製でUnity Constraint・VRC Constraint・PhysBone（Colliderを含む）を有効状態のまま約1秒更新してから撮影します。一時停止は解除してください。設定変更・モード切り替え・ウィンドウを閉じる操作で待機を中止します。元から無効なコンポーネントは有効化しません。物理挙動の収束を保証する待機時間ではありません。

保存先の初期値はプロジェクト直下の`Captures`です。毎回別のサブフォルダーを作り、既存画像を上書きしません。

| ファイル | 内容 |
| --- | --- |
| `face.png` | 顔アップ |
| `front.png` | 全身正面 |
| `right.png` | 全身右側面 |
| `back.png` | 全身背面 |
| `three-view.png` | 正面・右側面・背面を同じ縮尺で横に連結 |

## 動作と対応範囲

- 撮影には一時シーン内の複製を使用し、元アバターやシーンを保存・変更しません。
- `HumanBodyBones`の対応付けから上腕を取得して角度を合わせます。固定のボーン名照合は行いません。
- 肩・胴体・脚と、肘・手首・指のローカル姿勢は保持します。立ち姿のアバターを指定してください。
- 背景は単色・不透明または透明を選択でき、全身は正投影です。背景透過をONにすると背景色の指定は無効になり、プレビューと5枚すべてのPNGにアルファが付きます。プレビューの解像度は512pxです。
- 撮影用の複製では、ビルド時の衣装加工やAnimatorによる表情アニメーションを再実行しません。実行中アバターに反映済みの衣装・表情は撮影に使用します。編集モードでは物理挙動を更新せず、プレイモードでは上記のConstraint・PhysBoneとClothを更新します。その他のBehaviourは無効化します。VRChat内の照明は再現しません。
- プレイモードの物理更新後に画角を計算し、5枚とも同じフレームの状態を撮影します。PhysBone・VRC Constraintには、それらが動作するVRChat SDK環境が必要です。
- 元のシーンを変更しないため、アバター外部のTransformを動かすPhysBone・VRC Constraintはエラーにします。アバター外部を参照するConstraintの追従元・Colliderは、撮影用の複製に含まれません。
- ルートのスケールはXYZ共通の正の値が必要です。顔の自動画角は初期値なので、アバターに合わせて調整してください。

## 開発・検証

本体は`Editor`、アバター素材に依存しないパッケージテストは`Tests/Editor`にあります。
開発プロジェクトのChiffonを使う描画・姿勢・保存テストは、パッケージ外の`Assets/Tests/TakePhotoAvatar`にあります。

ローカルパッケージとして導入した際にパッケージテストを実行する場合は、プロジェクトのテスト対象パッケージ（`testables`）へ`com.gokoukotori.take-photo-avatar`を含めてください。
